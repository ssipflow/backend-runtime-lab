# G-05 문제: CPU / I/O 혼합 HTTP 서버
> net/http · GOMAXPROCS · 동시 요청 처리

Go 표준 라이브러리 net/http로 두 가지 작업을 처리하는 HTTP 서버를 구현합니다.

### 요구사항

1. GET /cpu는 고정된 횟수의 CPU 연산을 수행합니다.
2. GET /io는 200ms 동안 대기한 뒤 응답합니다.
3. 두 API는 모두 HTTP 200을 반환합니다.
4. /cpu는 계산 결과를 응답에 포함합니다.
5. /io는 "ok"를 반환합니다.
6. 서버 시작 시 GOMAXPROCS 값을 출력합니다.
7. 별도의 부하 테스트 코드로 각 API에 100개의 동시 요청을 보냅니다.
8. 두 API의 총 실행 시간과 요청 성공 건수를 비교합니다.

### 제약조건
- Go 표준 라이브러리만 사용합니다.
- CPU 연산 횟수는 요청마다 동일해야 합니다.
- 클라이언트는 sync.WaitGroup으로 모든 요청 완료를 기다립니다.
- 요청 성공 건수는 동시성에 안전하게 집계해야 합니다.
- CPU 테스트와 I/O 테스트는 각각 별도로 실행합니다.
- 서버는 로컬 환경에서 실행합니다.
